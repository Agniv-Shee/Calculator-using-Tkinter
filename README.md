# Tkinter Calculator

A simple graphical calculator application built using **Python** and **Tkinter**.  
This project demonstrates basic GUI programming concepts such as buttons, input fields, and event handling.

## Features
- Basic arithmetic operations:
  - Addition (+)
  - Subtraction (-)
  - Multiplication (*)
  - Division (/)
- Clear button to reset input
- Error handling for division by zero
- Simple and beginner-friendly GUI

## Requirements
- Python 3.x
- Tkinter (comes pre-installed with most Python distributions)

## How to Run
1. Make sure Python is installed on your system.
2. Download or clone this repository.
3. Open a terminal or command prompt in the project directory.
4. Run the following command:

```bash
python calculator.py
```

> Note: Rename the file to `calculator.py` if necessary.

## How It Works
- Numbers are entered using on-screen buttons.
- Select an operation (+, -, *, /).
- Enter the second number.
- Press `=` to see the result.
- Press `clear` to reset the calculator.
